# OpsPilot

OpsPilot 是一个基于钉钉 Stream 的企业 AI 运维助手，面向企业内部员工、IT 运维人员和系统管理员。

员工可以通过钉钉提出 IT 问题，系统会尝试理解问题、检索企业知识、引导排障；无法解决时转为人工工单，并在处理完成后将有效解决方案沉淀为可复用知识。

## 当前能力

- 钉钉 Stream 消息接入
- AI 问答与多轮排障
- IMA 与本地知识检索
- 工单创建、分派、处理、确认与通知
- Issue 问题上下文记录
- 知识候选、审核、发布和复用
- 图片、语音、文件与表格处理
- 管理后台、运行监控和配置管理
- 多个独立 AI API、按任务路由及顺序故障切换

## 本地运行

1. 安装 Python 3.11。
2. 安装依赖：

   ```powershell
   pip install -r requirements.txt
   ```

3. 复制配置模板：

   ```powershell
   Copy-Item config.example.yaml config.yaml
   ```

4. 在本机填写 `config.yaml`。不要提交真实密钥。
5. 启动：

   ```powershell
   python main.py
   ```

默认管理后台地址为 `http://127.0.0.1:8765`。

## 数据安全

仓库不应包含正式配置、API 密钥、工单数据库、Issue 数据库、聊天记录、日志或客户知识数据。正式运行数据应由部署方在受控环境中独立保存和备份。

默认管理后台只适用于本机访问。部署到企业共享服务器前，应补充身份认证、权限隔离、审计和网络访问控制。
