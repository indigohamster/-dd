# OpsPilot V2.17.3 历史快照

- 冻结日期：2026-07-31
- 版本：V2.17.3
- 用途：企业知识正文读取与本地知识闭环回归基线
- 本次未重新构建或发布 EXE；源码服务重启后加载新代码

## 本次改进

- IMA 标题命中后通过 `media_id` 获取带签名原文件，并提取文本、Markdown、HTML/XML/JSON 与 DOCX 正文。
- IMA 连接、搜索、默认知识库有效性和正文读取分别校验；读取失败明确返回真实原因。
- 媒体读取增加大小、上下文、单轮数量和缓存限制。
- 本地知识完成工单解决、用户确认、候选生成、审核、发布、相似问题检索和真实 AI 引用验证。
- 修复前端已更新但后端仍为旧进程时知识导出按钮出现英文 404；未知 API、旧后端和 Windows 打开目录失败均返回明确中文说明。
- 设置页新增可自定义知识导出目录，支持输入、Windows 目录选择、真实写入测试、保存和打开；相对路径限制在程序运行目录内，查看文件限制在当前配置目录内。
- 工单工作台新增只读 Issue 记录二级页面，支持状态和工单关联筛选、详情查看及关联工单跳转；继续使用原有 Issue 表，不改变任何业务状态。
- 工单详情顶部显示关联 Issue 的原始问题、用户、时间、已有步骤和最终结果；无 Issue 的历史工单保持原样，缺少 AI 处理标记时明确显示无法确认。
- 控制台、运行状态、打包脚本与文档统一为 V2.17.3。

## 真实性验证

- 当前配置中的 5 个默认知识库 ID 全部存在。
- U9 实际检索返回 81 条索引结果，其中 4 条正文可提取；部分 `media_type=99` 条目返回 IMA 业务码 `220030`，不会作为知识命中。
- 可读取 DOCX 实测提取 4884 个正文字符并进入 AI 上下文。
- 隔离测试工单从 `resolved` 经用户确认进入 `closed`，生成并发布本地知识；真实 AI 回答包含唯一解决步骤与知识标题。
