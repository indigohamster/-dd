# 历史版本保存规则

每次发布新版本时执行以下流程：

1. 开发前将当前稳定版本复制到 `releases/Vx.y.z/`。
2. 快照包含源码、测试、操作手册、更新日志和构建脚本。
3. 快照不得包含 `config.yaml`、真实 API 密钥、`data/`、`logs/`、`build/`、`dist/` 或 `__pycache__/`。
4. 完成开发后更新 `utils/console.py` 中的版本号、`CHANGELOG.md` 和 `操作手册.md`。
5. 全部测试通过后，再冻结新版本快照。

安全例外：V1.6.0、V1.7.0、V1.7.1 的旧手册曾包含完整 `sk-...` 形式密钥，已列入 `.gitignore` 隔离清单。对应密钥必须在提供商侧吊销或轮换；这些目录只能保存在受控内部归档，不能进入源码仓库或客户交付。V2.16.0 起的冻结快照必须同时附带发布清单和敏感标记扫描结果。
